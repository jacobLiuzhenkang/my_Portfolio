# 历史作品封面适配

日期：2026-10-24。使用内置 image_gen，根据原作品封面生成适合网站卡片的展示构图。生成与安全留白调整的完整提示词分别见 [prompts.json](prompts.json) 和 [safe-framing-prompt.txt](safe-framing-prompt.txt)。

## 尺寸与构图

实测 391px 手机视口下，双列卡片约为 168.5 × 126.375px（4:3）；1440px 桌面视口下为 604 × 300px，约 2:1。中等桌面尺寸沿用原有 16:10 容器。

每个项目提供三个 WebP 导出：

- `cover-adapted-v1-mobile.webp`：1200 × 900，4:3，手机使用更近的构图。
- `cover-adapted-v1.webp`：1600 × 1000，16:10，中等桌面使用。
- `cover-adapted-v1-wide.webp`：1600 × 800，2:1，大屏使用留白更充足的构图。

分别保留近景与宽景母版，避免把手机、指环、IP 头部、咖啡器具和插画主体裁掉。母版文件与项目对应关系见 [manifest.json](manifest.json)。

## 来源与内容边界

新图是基于原封面的 AI 展示构图，设备屏幕和局部图形可能经过重新表现，用于作品列表缩略图；不能代替案例正文中的实际界面、硬件设计图或项目成果证据。原始 `cover.webp`、案例正文和图集均保留。

前端只为五个已知原始封面路径选择对应的新图。管理员上传或改为其他封面地址时仍优先使用该地址，不改写数据库中的项目记录。
